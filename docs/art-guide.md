# 美术指南

噗全部用内联 SVG 手绘,画布 `viewBox="0 0 100 100"`,所有文件在 `frontend/src/components/poo/`。想换成正式插画,只替换这个目录。

## 分层(从后到前)

| 层 | 文件 | 说明 |
|---|---|---|
| 场景 | `characterKits/<属性>Kits.tsx` → `scene` | 仅形态 5。画在身体后面 |
| 光晕 | `Poo.tsx` | 仅形态 5,点缀色的淡圆 |
| 身体 | `PooBody.tsx` | 形态 1 拉稀 / 2 硬条 / 3 以上三层 |
| 道具 | `characterKits/<属性>Kits.tsx` → `prop` | 所有形态都有,在身体右下角 |
| 前景 | `characterKits/<属性>Kits.tsx` → `foreground` | 仅形态 5。压住身体下缘(钞票山、海浪、烤架) |
| 脸 | `PooFace.tsx` | 7 种心情;戴墨镜时不画眼睛 |
| 配饰 | `PooGear.tsx` | 形态 4、5 的帽子、口罩、领带等,画在脸上方 |

`showScene={false}` 会关掉场景和前景,用于头像、日历、签到印章等小尺寸场合。

## 坐标约定

- 形态 3 及以上:脸中心 `(50, 57)`,头顶 `y≈20`,身体横向 `x≈14~86`。**配饰按这个写死**,所以只在形态 4、5 使用。
- 形态 1、2:脸的 y 分别是 76、70,只有道具和脸需要适配(`Poo.tsx` 已处理)。
- **道具**在 24×28 的局部坐标里画,`Poo.tsx` 会 `translate(73 62)` 放到右下角。可以画到框外(比如垂下来的蜘蛛丝)。
- **场景/前景**用整张 100×100 画布。身体占掉中间大部分,**能看见的只有四个角和上下边缘**,所以背景要往角落放,或者画得足够大从身体后面透出来。

## 风格

- 描边统一用 `INK_COLOR`(`inkStyle.ts`),道具/场景小件描边 1.4~1.8,身体 2.5。
- 配色:道具用符合事物本身的颜色;场景可以用系列点缀色,避免整体太花。
- 小件复用 `characterKits/sharedShapes.tsx`(金币、四角星、泡泡、火焰、蘑菇、宝石、病菌、雪花)。
- 重复出现的图形写成有名字的小组件(`<RedLantern x={13} />`、`<BanknotePile ... />`),参数用完整名字(`radius`、`scale`、`rotation`),不要写 `r`、`s`、`a`。SVG 坐标 `x`、`y`、`cx`、`cy` 除外。

## 验证

画完请实际看一眼,别只靠类型检查。临时写一个测试用 `renderToStaticMarkup(<Poo .../>)` 输出 HTML,再用浏览器打开,把 4 个形态(1、3、4、5)排成一行对比,尤其看形态 5 的场景有没有挡住脸。

**重构美术代码时**,先把改动前每只角色 × 每个形态 × 每种心情的渲染结果存成哈希快照,改完再比对,必须逐字节一致。画面不变是重构的底线。
