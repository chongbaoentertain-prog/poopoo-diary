# 噗噗日记

养成式的排便打卡 app。每天签到攒经验,培育一只噗一步步进化成最终形态;每次签到选一个今天的心情,日历和图鉴都会记住;还能把某一天或一段时间做成搞笑卡片分享给朋友。

> 打卡日志本质上不该有登录这一步。所以这里没有账号:数据先存在本机,需要多设备同步时,用一个「存档码」就能找回。

## 功能

| | |
|---|---|
| **签到** | 每天第一次签到计经验,同一天再签只记录不计经验。可补签过去的日子,也可批量补签 |
| **连续奖励** | 连续天数越长,经验倍率越高 |
| **进化** | 经验达到阈值进化,共 5 个形态。满级后可毕业进图鉴,再选一只新的 |
| **心情** | 签到时选 7 种心情之一(从好到坏):舒畅、淡定、躺平、憋屈、泄气、嫌弃、崩溃。日历显示当天最新一次的心情,图鉴显示该角色最近一次的心情 |
| **角色图鉴** | 7 个属性(金木水火土衰弱中毒)× 每属性 3 只,共 21 只 |
| **分享** | 选当天、近 7 天、本月或自定义范围(最多 42 天),生成卡片后以图片分享或下载。可隐藏昵称和心情 |
| **多设备同步** | 首次打开自动生成存档码,换设备输入它即可找回。离线照常签到,联网自动补同步 |
| **清空与恢复** | 一键清空全部数据,需输入「清空」确认。30 天内可以恢复 |

## 角色:名字是什么,画面里就有什么

每只噗都按名字设计:

- 社畜噗拎着公事包,进化到最终形态时置身办公室,头顶飞着文件、身边堆着文件山
- 首富噗带着钱袋,最终形态站在钞票山里
- 竹子噗的最终形态四周是满屏竹林
- 海盗噗戴海盗帽和眼罩,脚下是大海和帆船

形态 1 到 3 是噗本体,形态 4 加上专属配饰,**形态 5 解锁专属场景**。

分享卡片上的文案也跟着角色走。比如社畜噗是「像牛马一样,在屎海中奋力前行」。

完整名册见 [docs/characters.md](docs/characters.md)。

## 没有账号,怎么同步?

**存档码**:第一次打开 app 时,本机静默生成一个存档码,形如 `K7MQ-X2PD-9WTR-4HJF`。

- 换手机、换浏览器时,输入存档码就能把记录找回来,和本机已有的记录自动合并。
- 服务器只保存存档码的哈希值,**拿不到存档码本身**。
- 谁有存档码,谁就能看到这份记录,所以不会出现在分享卡片里,也不建议发给别人。
- 没有「找回存档码」的途径,所以签满 3 天后会提醒保存。

**本地优先**:页面始终读写本机存档,后台再和云端对齐。因此离线也能签到,联网后自动补同步,多台设备的数据自动合并。同一天在两台设备都签到,只有最早的一条计经验,不会重复加。

**清空是软删除**:清空后云端数据先被标记删除,保留 30 天,期间可以一键恢复;超过 30 天永久清除。

云端同步是可选的,不启用时完全本地使用。设计、合并规则和安全模型见 [docs/sync.md](docs/sync.md)。

## 常见问题

**输入存档码后什么都没恢复?**
先确认原来的设备显示「已同步」。没同步完,云端是空的。可以在「个人」页点「检查云端数据」,核对云端有多少记录。

**清空之后输入存档码为什么还是空的?**
存档码只是找回云端数据的钥匙,清空后云端数据已被标记删除。要找回请用「恢复清空的数据」,30 天内有效。
